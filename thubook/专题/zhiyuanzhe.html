                                                                                                    # 志愿者

                                                                                                    # 志愿资源

                                                                                                    校内的志愿信息主要发布在微信公众号 “清华大学学生公益” 上。各院系也会组织自己的志愿服务项目，除了一些品牌项目，大部分服务面向院系内部。

                                                                                                    # 星级志愿者评选

                                                                                                    每年5月左右会进行清华星级志愿者的评选，评选标准基于志愿北京网站open in new window上的志愿工时和项目数量，星级从低到高依次为一星到五星志愿者。具体规则如下（摘自“清华大学紫荆志愿者分级嘉许办法”）：

                                                                                                    • 在志愿北京平台注册并填写个人信息，注册成为志愿者，加入“清华大学紫荆志愿服务总队”志愿团体，至少参加过一次志愿服务并获得认证时间，可获得**“一星级紫荆志愿者”**称号。
                                                                                                    • 志愿服务认证时间累计达到20小时，可获得**“二星级紫荆志愿者”**称号。
                                                                                                    • 志愿服务认证时间累计达到50小时，可获得**“三星级紫荆志愿者”**称号。
                                                                                                    • 志愿服务认证时间累计达到120小时，且至少参加过3次不同的志愿项目，经审核后可获得**“四星级紫荆志愿者”**称号。
                                                                                                    • 志愿服务认证时间累计达到200小时，且至少参加过5次不同的志愿项目，经审核后可获得**“五星级紫荆志愿者”**称号。

                                                                                                    此外，每年奖学金评选中还有“志愿优秀奖学金”一项，用于表彰在志愿服务方面表现突出的同学。
